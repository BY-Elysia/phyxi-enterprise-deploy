# 企业接入与下载进度

## 页面分工

“企业网关”顶部仅展示共享网关服务状态和准备按钮，下方列表管理具体访问入口。点击入口进入独立详情页，编辑配置、上传证书、启用与验收均在详情内完成。服务维护、日志和最近任务默认折叠；进行中的准备任务自动展开。一个网关服务承载入口配置，准备服务不等于启用入口。

“服务器资源与依赖”只展示宿主机资源、显卡、软件依赖及 NVIDIA 容器支持维护，不再加载或展示接入组件。

操作顺序：准备 Nginx / 工作区鉴权 → 配置网关证书及入口 → 在客户端工作区配置密钥 → 启用网关并验收。首次准备只启动内部组件；恢复已有容器可能恢复已启用入口。停止接入组件会中断经过它们的请求和企业管理入口，模型容器及 SSH 控制台继续工作。

## 下载可视化

模型权重、推理镜像、企业接入和操作记录复用同一进度卡片。

- 权重：清单大小完整时显示总体百分比、累计已下载/总大小、采样速度、当前文件和已校验文件数。字节数来自临时文件实际大小；总量未知时仅显示当前文件字节与 curl 报告的文件百分比，不估算总体百分比。传输完成后仍需逐文件校验；下载中可直接中断当前 curl 进程。
- Docker 镜像：仅数字展示百分比、已准备/总大小（含本地缓存）、采样速度和各层状态，不显示横条。通过 Docker CLI 终端输出捕获每层真实下载数据；镜像清单匹配 Linux/当前架构后计算总量。下载字节完成后仍可能解压或校验，以任务成功为最终完成。
- 清单不可用或实际层与清单不一致时，降级为已就绪层数及各层数字，不估算全局百分比。网络速度来自采样差值，Docker 输出单位有舍入，不提供预计剩余时间。
- 进度以每任务快照保存到 SQLite settings，不依赖浏览器会话。每秒最多更新一次；最多记录 512 层，终端尾部和行缓冲有界。接口不暴露解析缓冲和内部清单。
- “中断下载”直接调用现有取消接口，不新增确认弹窗或中断说明。取消仅终止本任务的 Docker 拉取客户端，保留 Docker 管理的缓存；重试重新执行拉取，由 Docker 复用可用层，不承诺未完成层按字节续传。
- 展开的层详情在轮询时保持展开；状态约每三秒更新，不新增 WebSocket、队列或监控容器。
- 下载失败给出中文下一步和重试按钮，原始诊断折叠展示。接入任务的最近结果在返回页面/刷新后仍可见。

## 服务器验收

在 47.120.39.81 的隔离目录 `/srv/phyxi-progress-preview` 和仅回环监听端口 18770 运行待提交版本，通过 SSH 隧道查看；使用真实 Docker，不操作其他归属的容器。

- 真实准备 Nginx/鉴权、停止、恢复与幂等再次准备；恢复保持容器 ID，初始 Nginx 配置只监听回环。
- 用回环不可达仓库做受控失败测试，验证镜像阶段失败提示；恢复默认来源后从页面重试。
- vLLM 限时实际拉取 48 秒，识别 33 个层，显示缓存/等待/下载完成，最终取消成功；没有启动模型，也没有完成大镜像下载。
- 权重百分比用协议夹具验证，并验证校验失败不会变成任务成功；不把夹具当真实权重或 GPU 推理验收。
- 服务器 cargo fmt / clippy / test / build、smoke-console、API contract、presets、executor、composition、backup-restore、admin-security 均通过。测试后按 owner 清理测试组件和预览进程，保留生产控制台。

## 默认配置的展示

镜像下载方式与网关镜像仅显示“默认”；选择企业仓库或自定义时才显示地址输入。默认网关镜像值由 API 返回，前端不复制固定摘要；保存默认/自定义不影响现有服务。默认推理镜像列表摘要不显示原始地址，新建预设隐藏地址输入，自定义时可编辑。实际下载地址、镜像 ID 和原始下载来源保留在详情/诊断中。
