# 企业接入与下载进度

## 页面分工

“企业网关”第一部分管理接入组件：准备/恢复、停止、运行状态、组件日志、最近组件任务及诊断详情。下面的配置列表管理域名、证书、模型后端和入口规则。

“服务器资源与依赖”只展示宿主机资源、显卡、软件依赖及 NVIDIA 容器支持维护，不再加载或展示接入组件。

操作顺序：准备 Nginx / 工作区鉴权 → 配置网关证书及入口 → 在客户端工作区配置密钥 → 启用网关并验收。首次准备只启动内部组件；恢复已有容器可能恢复已启用入口。停止接入组件会中断经过它们的请求和企业管理入口，模型容器及 SSH 控制台继续工作。

## 下载可视化

模型权重、推理镜像、企业接入和操作记录复用同一进度卡片。

- 权重：当前文件序号/文件总数、文件名、curl 实际报告的当前文件百分比。单文件 100% 不表示整个模型已就绪，仍需校验及其余文件。
- Docker 镜像：处理中进度条、已识别层数、就绪/缓存层数及各层中文状态。Docker CLI 在非终端模式不持续提供总字节数，不能把层数百分比当成字节下载百分比，因此不估算总百分比、网速或剩余时间。
- 连接阶段尚未返回层信息时，显示等待工具更新。成功、失败、取消、重启中断均停止活动进度条；下载中的资源状态显示“下载中”，不提示用户重复下载。
- 进度以每任务快照保存到 SQLite settings，原始日志仍保留；不依赖当前浏览器 session、activeJob 或日志尾部。接口隐藏未完成行缓冲。最多记录 512 个层，行缓冲有上限。
- 展开的层详情在轮询时保持展开；状态约每三秒更新，不新增 WebSocket、队列或监控容器。
- 下载失败给出中文下一步和重试按钮，原始诊断折叠展示。接入任务的最近结果在返回页面/刷新后仍可见。
