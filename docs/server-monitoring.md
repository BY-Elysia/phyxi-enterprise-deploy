# 服务器实时监控

服务器页分为实时监控、GPU 资源、软件与依赖。实时页显示 CPU、内存、磁盘 I/O、网络吞吐与数据目录磁盘容量。可选择最近 1、6、24 小时，并暂停页面每 15 秒刷新；暂停只影响浏览器，后台采样继续运行。

点击实时监控或 GPU 资源中的任一趋势图即可放大。放大视图沿用当前时间范围、采样和自动刷新设置，可按 Esc 或点击关闭返回原图。

## 数据与范围

- 内置 Rust 采样，每 15 秒执行一轮只读查询；无额外监控服务、Node 构建或第三方监控账户。
- Linux CPU 来自 /proc/stat 相邻采样差值，不把 load average 当 CPU 百分比；macOS 使用 top 两次采样中的第二次，表示最近 1 秒窗口。页面标明该差异。
- Linux 内存以 MemAvailable 计算；macOS 空闲、inactive、speculative 页作可回收估算，页面注明估算。
- Linux 磁盘 I/O 为 /sys/block 中具有 device 的整块设备，以 /proc/diskstats 扇区差值计算（512 字节/扇区），排除分区、loop、device-mapper 重复层；macOS 为 IOBlockStorageDriver Statistics 的字节差值。不是数据目录单独产生的 I/O。
- 网络为全部可见非回环接口收发字节差值；macOS 只取 Link 行，避免同一接口按 IP 地址重复计数。虚拟接口、桥接、隧道可能覆盖同一流量的不同阶段，因此该合计不是单一物理出口带宽；未提供每接口筛选。
- 磁盘容量来自数据目录所在挂载点。使用比例以已用/总量计算；可用空间由操作系统返回，保留空间可能使已用+可用小于总量。
- 原生进程显示本机范围，执行器模式由宿主机执行器采集，普通 Docker 模式显示容器采样范围。后者的网络位于容器命名空间，CPU/磁盘可见性受挂载及系统配置限制，不能作为完整宿主机监控认证。

## 历史与异常

认证接口 GET /api/monitor 返回 samples 和 metadata；沿用既有认证和执行器转发。SQLite monitor_samples 逐条存储，每轮事务清理超过 24 小时的数据，且最多 5760 条；重启保留历史。旧版本升级不会生成历史补点。

首次差值、读取失败、设备集合变化、计数器回退或超过 60 秒间隔均返回 null。前端将 null 与真实零值区分，超过 45 秒的采样空隙不连线；最后采样超过 45 秒标注过期。接口故障保留图表并明确标注读取失败。浏览器隐藏后停止刷新，但服务端继续采样。

## GPU 资源

每张 NVIDIA GPU 按设备编号显示当前计算利用率、已用和总显存、显存占用率及 UUID。两条趋势线按 UUID 关联样本。计算利用率来自 `nvidia-smi` 的 `utilization.gpu`，显存占用率用已用显存除以总显存计算。计算利用率为 0% 时，显存仍可能被其他进程占用。GPU 资源页不改变模型部署的 GPU 选择或空闲检查。

GPU 复用执行器现有约 10 秒一次的只读采样。扩展查询失败时，沿用基础查询提供显存信息。认证接口 `GET /api/monitor/gpus?seconds=3600` 支持 1、6、24 小时。SQLite 保留最近 24 小时，新版本从首次采样开始积累。长时间范围每 60 或 180 秒取该时间段最后的真实样本，短时峰值可能落在采样点之间。设备不可读、指标不受支持和历史间隙以缺失数据处理。时间范围、自动刷新和手动刷新与服务器实时监控共用。

## 验证

Rust 测试覆盖不同平台解析、差值、重置、空数据、设备变化及历史持久化与过期清理。scripts/test-server-monitor-ui.py 使用隔离服务器真实主机采样与八卡 NVIDIA 查询夹具，覆盖认证、图表、页签、时间范围、暂停、null/零值、过期/故障恢复、移动布局和无部署副作用。

本分支验证使用 macOS 本机采样、隔离执行器和八卡 NVIDIA 查询夹具。
