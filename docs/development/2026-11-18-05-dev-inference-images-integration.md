# 合入推理镜像目录

## 目标

按模块合入推理镜像目录、服务器已有镜像检测与配套后端配置。

## 变更

- 合入 feature/inference-image-catalog，在服务端同时提供模型权重与推理镜像两套目录接口。
- 整合共用编辑器、列表和保存逻辑。已有权重仍按服务器根目录检测，已有镜像仍按引擎和平台复核，保存不可变 ID。
- 更新运维浏览器回归，覆盖两个目录页、已添加列表及详情之间的导航。

## 验证

- Rust 格式、Clippy、工作区测试、锁定依赖构建、控制台冒烟、API 合约和执行器检查。
- 模型目录与路径选择、镜像目录与版本选择、网关证书、运维导航和推理参数浏览器回归。
- 镜像预设接口测试覆盖显式拉取、不可变镜像 ID 及三个推理后端的模拟启动参数。

## 限制

LMDeploy、SGLang 和 vLLM 在此次合入中使用模拟 Docker 验证参数，未执行 GPU 实机推理或服务器更新。
