# 合入服务器资源监控

## 目标

在独立合并中纳入服务器资源监控和逐卡 GPU 趋势。

## 变更

- 合入 feature/server-monitoring 的采样、查询、执行器转发和图表。
- 合并共享页面与静态资源路由，保留模型权重目录、推理镜像目录、网关及客户端入口。
- 保留监控自己的刷新逻辑和时间范围设置。模型权重与镜像页各自记住所选标签页，使刷新详情后返回时恢复原来的目录或已添加列表。

## 验证

- Rust 格式、Clippy、工作区测试、构建、控制台冒烟、API 合约和执行器转发。
- 本地服务器监控浏览器测试及模型权重、镜像、网关证书、运维和推理参数回归。
- 对照 origin/dev 检查每个合并提交的开发纪要。

## 限制

验证使用本机采样与 GPU 夹具，未在目标 GPU 服务器上运行。监控历史从新版本开始采样。
