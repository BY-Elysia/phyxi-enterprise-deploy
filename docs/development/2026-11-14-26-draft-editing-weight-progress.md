# 下载期间保存草稿与权重数字进度

## 目标

修复执行任务时无法新建模型配置的问题；模型权重下载与推理镜像一样显示可理解的数字进度。

## 变更

- 草稿写入改用独立异步互斥锁；模型来源解析在锁外进行，目录读取、修订检查和保存原子串行。删除和证书更新也使用此锁，避免覆盖并发编辑。
- 新增/编辑草稿不占执行锁，运行任务保持提交时的配置与依赖快照；任务卡显示与当前草稿不同的版本。删除与共享资源变更保持保护。
- 权重使用仓库文件清单计算已知总量，每秒读取临时文件大小显示累计字节、速度、文件进度和已校验数量。总量缺失时不估算；没有新增横条。
- 权重元数据获取及文件传输响应任务级取消；校验和持久化成功后才算任务成功。

## 验证

- 47.120.39.81 隔离目录 fmt、clippy -D warnings、cargo test（30 通过、1 忽略）、build 通过。
- 服务器 smoke-console、test-api-contract、test-presets、test-executor、test-composition、test-admin-security 通过；最终前端调整后重建并重跑 presets、smoke/API contract。
- HTTP 测试覆盖下载期间新建模型/镜像配置、修改运行任务对应草稿且原任务快照不变、重复资源仍拒绝。权重夹具覆盖部分字节/总量、文件中途取消、重试成功、校验失败不变成成功。
- 服务器从 hf-mirror 实际下载 Qwen/Qwen3-0.6B 的 config.json（726 字节），验证来源解析、文件下载及最终字节进度。未下载完整模型或启动推理。
- 前端 JS 语法和 git diff --check 通过。

## 限制

- 仓库缺少任一文件大小时，总百分比不可用；实际下载量包括本地已校验文件，速度按采样计算。
- 当前权重重试会复用完整且校验通过的文件，不承诺未完成文件断点续传。
- 配置删除、下载来源修改和实际应用接入配置仍受执行锁保护；本次开放的是独立草稿新建与编辑。
- 本次无浏览器截图验收；真实仓库测试仅为小配置文件，不代表完整模型或 GPU 推理验收。
