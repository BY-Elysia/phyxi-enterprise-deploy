# 独立下载并发与定向中断

## 目标

下载推理镜像时可以同时准备企业网关或下载其他资源，中断只影响所选任务。

## 变更

- 配置读写锁替代全局任务信号量，下载及网关准备共享读锁，其他控制操作保持独占锁。
- 任务注册表最多允许三个并行任务，按实际镜像来源、权重版本目录和网关组件避免重复；RAII 释放资源，所有取消标记按任务隔离。
- 中断 API 支持 job_id，两个前端中断入口均传入任务 ID。旧客户端只在单任务时允许省略 ID，多任务拒绝歧义请求；不增加弹窗或冗余提示。
- 补充架构文档、注册表单元测试和真实 HTTP 并发回归。

## 验证

- 在 47.120.39.81 隔离目录运行 fmt、clippy（-D warnings）、cargo test（30 通过、1 忽略）、build，通过。
- 服务器 smoke-console、test-api-contract、test-presets、test-executor、test-composition、test-admin-security 全部通过。
- HTTP 夹具证明三个下载并行、相同资源/第四个任务/冲突模型操作被拒绝、无 ID 多任务取消被拒绝；取消一个后其余两个成功，资源释放后可以重试。
- 服务器真实 Docker 测试：SGLang 镜像拉取与企业网关准备同时被接受；网关完成后拉取仍运行；定向中断拉取不停止网关。测试结束仅停止删除测试 owner 的网关/鉴权组件和预览进程，生产下载保持运行。
- 前端 JavaScript 语法检查及 git diff --check 通过。

## 限制

- 上限固定为 3，不增加队列或调度服务；模型/宿主机/网关变更继续保守互斥，配置编辑在任务期间仍受保护。
- 不承诺不同标签指向相同远端内容的下载去重；资源键按解析后的来源判断，底层共享层由 Docker 管理。
- 大镜像未完整下载，没有启动 GPU 模型。本次未做浏览器截图验收。
