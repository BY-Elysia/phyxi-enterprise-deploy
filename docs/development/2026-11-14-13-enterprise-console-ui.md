# 企业控制台前端统一整理

## 目标

解决页面信息层次粗糙、配置表单拥挤、任务/验收以原始文本输出为主、加载与空状态不一致的问题，保持轻量部署边界。

## 变更

- 重整登录页、分组导航、面包屑、账户区、配色、留白、表格和响应式布局。
- 六类配置列表增加数量、搜索、明确的查看/编辑和空状态；配置抽屉按业务字段分组，统一操作区。
- 部署详情统一状态卡片与参数区；无所属实例时禁用相关操作和实例日志，避免正常未部署状态产生错误。
- 任务列表/详情、配置快照、管理员审计、验收结果和发布历史改为结构化展示；仅真实日志保留等宽区域。
- 增加资源检测加载反馈、证书/密钥弹窗样式和密钥复制反馈；保留现有自定义确认弹窗及提示生命周期。
- 新增 docs/frontend-design.md，明确页面职责、交互规则和回归范围。未引入前端依赖或构建管线。

## 验证

- cargo fmt --all -- --check；cargo clippy --workspace --all-targets -- -D warnings；cargo test --workspace；cargo build --workspace。
- python3 scripts/smoke-console.py；python3 scripts/test-api-contract.py；python3 scripts/test-admin-security.py。
- node --check console/web/app.js；node --check console/web/login.js（仅语法检查，不引入 Node 构建）。
- 使用 SQLite 一致快照和独立数据目录在 8767 浏览器检查：登录、部署列表搜索与空结果、独立详情、配置检查反馈、六类配置表单打开/取消、镜像/网关/工作区空状态、资源检测、历史任务与验收结果。检查时无浏览器脚本错误；另检查 390 px 窄屏列表并恢复默认视口。
- 最终通过本地 Docker 构建更新控制台，复核页面和无实例操作禁用状态。

## 限制

本次集中调整界面与交互，不改变运行时、认证策略和配置存储协议。浏览器检查未执行模型启动、证书上传或真实工作区密钥变更；已有后端契约/安全测试负责对应 API 回归。未进行全平台视觉兼容性或真实 GPU 测试。
