# 模型权重目录与服务器已有权重

## 目标

把模型发现、下载配置和已有权重导入放到模型权重模块，支持不同服务器的存储布局。

## 变更

- 模型广场提供 Qwen、GLM、DeepSeek 预设、筛选、分页和已添加列表。保存下载配置时固定来源版本，下载仍由显式操作触发。
- 添加已有权重可直接粘贴服务器绝对路径，或显式选择根目录后浏览并选取模型目录或 GGUF。服务器检测通过后保存实际路径。额外目录由 `--model-root` 或 `PHYXI_MODEL_ROOTS` 配置。
- 权重浏览由执行器读取，拒绝目录遍历和越出允许目录的软链接。导入保留文件原位，执行时只读挂载。

## 验证

- Cargo 格式、Clippy、工作区测试和锁定依赖构建通过。
- `smoke-console.py`、`test-api-contract.py`、`test-executor.py`、`test-presets.py` 通过。
- Chrome 端到端覆盖筛选、保存与显式下载、绝对路径错误、缺失权重分片、手动切换根目录、目录浏览和 GGUF 选择。

## 限制

浏览单次返回至多 200 个条目。文件检测覆盖配置、权重分片和 GGUF 文件头，可加载性由部署验收确定。本次验证使用测试数据，没有在 H20 上部署或启动模型。
