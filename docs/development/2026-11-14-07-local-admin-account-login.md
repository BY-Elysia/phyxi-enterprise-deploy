# 本地管理员账户登录

## 目标

按用户要求将现有本地控制台从访问令牌切换为管理员账户和密码登录。

## 变更

- 密码模式页面显示管理员账户与密码，账户为 admin；后端验证账户，错误账户不能登录。兼容已有只提交密码的内部测试客户端，默认账户仍为 admin。
- 本地 Compose 显式启用回环 HTTP 会话模式，仍禁止通过非回环地址使用该模式；企业 Compose 的 HTTPS 安全 Cookie 不变。
- 本地显式开发模式允许 8–256 字节密码，企业模式保持 12–256 字节。
- 已停止本地所属控制台、用 stdin 设置用户指定密码，仅持久化 Argon2id 哈希，再重建镜像启动。存在管理员哈希后旧 Bearer Token 被拒绝。密码未写入提交，原配置保留。

## 验证

- fmt --check、clippy --all-targets -D warnings、cargo test、cargo build 通过。
- smoke-console.py、test-api-contract.py、test-admin-security.py、node --check 通过。
- 安全测试覆盖本地较短密码设置、企业拒绝短密码、错误账户、密码登录、Cookie/CSRF、旧令牌拒绝、退出和限速。
- Docker 镜像构建及本地重启通过；实际8765接口使用用户指定密码登录成功，Cookie 可读取配置，错误账户和旧令牌被拒绝，退出后会话失效。

## 限制

- 单一共享 admin 账户，不提供多用户管理。
- 本地使用回环 HTTP；企业仍使用独立 HTTPS 部署。不自动把开发密码复制到服务器。
- 未初始化管理员的原生兼容测试目录仍支持旧测试鉴权；本次本地实例已切换为密码模式。
