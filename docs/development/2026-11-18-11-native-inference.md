# 本机 vLLM 环境与已有服务

## 目标
在单台服务器复用现有推理环境，区分平台管理的实例和只读登记的服务。

## 变更
部署页增加接入方式。环境探测检查 PATH、VIRTUAL_ENV、CONDA_PREFIX 及运维指定的 PHYXI_VLLM_BIN；安装时可重复指定 --vllm-bin。原生启动与容器共享受校验的 vLLM 参数，检查 GPU 是否空闲并设置 CUDA_VISIBLE_DEVICES。Linux 特权执行器通过绑定其生命周期的 systemd 临时服务和动态用户 phyxi-vllm 启动，独占作业名及进程组，监听回环地址。通过本机端口检测已有服务，选定 /v1/models 返回的模型后登记，外部服务无启停操作。

## 验证
通过 Rust 格式、Clippy、工作区测试、冒烟、API 契约、浏览器及预设集成测试。使用独立测试进程模拟 vLLM 并检查发现、启动、状态和停止。另一个测试服务在登记、拒绝启停、删除登记之后仍可调用。

## 限制
已有服务需提供无需凭据的本机回环 HTTP 模型列表。原生运行要求执行用户能读取所选模型及 vLLM 环境、访问 GPU，且安装版本支持配置的参数。未在真实 GPU 或 Linux systemd 上执行模型推理。
