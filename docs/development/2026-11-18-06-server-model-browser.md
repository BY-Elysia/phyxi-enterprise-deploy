# 从服务器数据盘发现并导入已有模型

## 目标

在模型权重页面浏览现有数据盘或打开指定目录，直接添加平台默认权重目录之外的模型。

## 变更

- 模型路径选择器显示可发现的数据盘、常用数据目录和运维已配置的权重目录。浏览器记住最近打开的目录，仍由用户选择起点。
- 执行器只列出子目录和 GGUF 文件。允许用户明确打开宿主机可访问的数据目录，过滤系统目录、平台凭据目录以及越出所选目录的软链接。
- 权重通过检测后才保存。原允许范围之外只注册具体模型目录或 GGUF 文件，与模型记录同次写入。部署检查实际路径与注册项，其他目录不继承权限。删除记录或修改其路径会撤销原注册。

## 验证

- Cargo 格式、Clippy、锁定依赖构建和 Rust 测试通过。
- 控制台冒烟、API 契约和隔离执行器测试覆盖外部模型路径检测、注册持久化、挂载范围和系统目录拒绝。
- Chrome 验证从页面打开额外目录，选择 GGUF 保存，下一次打开时看到该目录，并确认原文件内容未变。

## 限制

自动发现受执行器可见的挂载点、文件类型、系统权限和目录可读性限制。目录浏览逐层进行。此次验证使用本地测试数据与隔离执行器，H20 运行版本未更新。
