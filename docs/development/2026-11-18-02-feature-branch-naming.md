# 按模块命名功能分支

## 目标

统一使用 feature/<模块名>，保留 main 和 dev 的名称。将规则留在仓库开发约定中。

## 变更

- 网关分支改为 feature/gateway。其他功能分支按证书管理、vLLM 参数、推理镜像目录、本地模型导入等模块命名。
- 同步本地和 GitHub 上原 codex/ 分支的名称。现有工作区跟随各自的分支。
- 在 AGENTS.md 中约定新分支使用 feature/ 前缀。

## 验证

- 对照本地和 GitHub 的分支名称、提交及默认分支。
- 验证开发纪要检查，并运行仓库要求的格式、Clippy、单元测试、构建、冒烟和 API 合约检查。

## 限制

本提交只更新开发约定，保留在网关功能分支。
