# 2026-11-12 · 独立配置库与组合部署

## 目标

将全局模型表单拆成可独立创建与复用的配置，部署时组合引用；企业网关和客户端工作区保持各自职责，同步调整前端并推送 dev。

## 变更

- 新增 catalog 领域模块、catalog_api 接口模块：模型、镜像、运行参数、部署、网关、工作区分别保存，具名记录与修订号、引用完整性和删除保护。
- 旧配置只迁移一次，保留旧 API 兼容验收脚本；空白数据库不生成占位配置。组合结果执行前校验，并持久化依赖树快照。
- 新增镜像拉取及本地镜像状态查询；操作显式绑定对象，停止时验证运行实例归属。网关发布记录使用实际模型启动快照，不使用修改后的共享草稿。
- 工作区导出网关地址、模型和凭据环境变量引用的 OpenCode 模板，不包含服务器密钥；企业证书归属网关，不进入 vLLM 参数。
- 前端新增独立配置列表/抽屉、引用选择器、GPU UUID 选择、当前页执行日志；保留操作历史和快照。服务器环境增加内存/磁盘/负载、GPU 和实际运行 vLLM 版本检查，Mac NVIDIA 项显示不适用。
- 更新 README、架构与组合 API 文档。本地预览升级前备份数据库；保留可复用的小模型演示配置，演示推理结束后停止实例。

## 验证

- cargo fmt、严格 Clippy、17 项 Rust 测试、debug/release 构建通过。
- smoke-console.py、test-api-contract.py 通过，兼容既有运行生命周期和协议验证。
- 新增 test-composition.py：独立 CRUD、无效引用、被引用删除保护、陈旧修订拒绝、实例归属、共享配置修改后的快照、导出凭据引用及重启持久化通过。
- 原有 `test-small-model.py` 使用明确的 llama-server/Nginx/GGUF 路径通过；该轮控制台采样峰值 5936 KiB，模型 286832 KiB，网关 8592 KiB，非长期压力测试。
- 同一组合测试使用本地真实 SmolLM2 <200 MiB GGUF、llama.cpp、Nginx，通过 CPU 文本/SSE、TLS、发布，以及运行参数草稿变更后发布仍绑定原模型快照。
- 浏览器验证模型和运行参数独立创建、部署引用选择、启动进度原页展示，真实文本和 SSE 验收成功；本次测试模型已停止。

## 限制

- 单服务器、单活动模型与单活动网关；多个配置方案不等于多实例调度。替换模型/网关仍有停机窗口。
- 镜像仍要求固定摘要；没有私有仓库认证 UI、自动识别标签摘要或后台调度。
- 工作区导出为客户端模板；真实企业 CA、工作站/OpenCode 接入和 GPU/vLLM 推理本轮未验收。工作区共用活动网关的认证令牌，不是多租户凭据体系。
- 旧无作用域 API 只为兼容保留，旧草稿与新配置库首次迁移后互不联动。旧实例无组合归属时须先用旧接口停止。
- 浏览器自动化的原生停止确认弹窗导致工具超时，已通过同一对象的 API 完成停止并确认 absent；不是服务停止失败。
