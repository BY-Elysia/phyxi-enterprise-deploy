# 控制台界面与相对权重路径

## 目标

将桌面工作区中尚未进入 main 的界面与权重导入改进整合到已验证的控制台版本。

## 变更

- 采用 PhySpace 控制台和登录页视觉。将六类配置的保存列表统一为资源卡片，保留搜索、编辑、详情和网关操作。
- 部署页显示紧凑的当前服务状态。详情只展示正在执行的任务，历史在运维与审计查看。同步监控布局和软件依赖文案。
- 权重路径选择器支持在显式选择的服务器根目录下输入相对路径。服务端检查路径边界和权重文件，保存解析后的绝对路径。保留已有绝对路径和目录选择方式。
- 保留独立的监控与权重路径脚本、现有 CA 导入和 GPU 采样回退。

## 验证

- Rust 格式、Clippy、工作区测试、锁定依赖构建和控制台冒烟通过。
- API 合约、执行器、预设、证书和管理员认证回归通过。执行器测试覆盖相对路径、缺失根目录、未授权根目录、上级路径及越界软链接。
- Chrome 检查六类卡片、搜索、编辑、详情返回、桌面及移动端，并通过权重、镜像、监控、运维、证书和推理配置回归。

## 限制

本次不包含原工作区的设计稿、独立测试文件和文稿。浏览器及 API 验证使用隔离数据，没有在服务器上部署或运行 GPU 模型。
