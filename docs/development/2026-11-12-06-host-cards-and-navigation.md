# 2026-11-12 · 中文服务器指标卡片与导航释义

## 目标

把服务器环境页的整块命令输出改成易读卡片，并说明模型权重、推理镜像、运行参数与部署实例各自的用途。

## 变更

- 新增只读 host_metrics 模块，分别解析 Linux /proc/meminfo、macOS vm_stat/sysctl、数据目录所在文件系统的 df 和 uptime。
- 返回结构化内存、磁盘、1/5/15 分钟系统负载与逻辑核心数。未知值保留为空；Mac 内存明确标注估算及可回收口径，不将系统负载冒充 CPU 百分比。
- 环境页改为内存、磁盘、负载、控制台进程、GPU 和软件依赖卡片，展示中文摘要、版本与占用条；英文诊断输出默认折叠。
- 导航改为部署实例、模型权重、推理镜像、vLLM 参数；同步更新页面职责和部署引用选择器说明。API 路径、配置 ID 和已保存引用不变。

## 验证

- cargo fmt、Clippy -D warnings、19 项 Rust 测试、debug/release 构建通过。
- 新增 Linux/Mac 内存单位、无效数据、磁盘单位以及两种平台负载输出解析测试。
- smoke-console.py、test-api-contract.py、test-composition.py 与 JavaScript 语法检查通过。
- 本地真实环境接口读取到 16 GiB 总内存、磁盘可用量与三组负载；浏览器检查中文卡片、进度条、依赖版本和折叠诊断正常。
- 本地预览已更新，未启动模型或改动远程服务器。

## 限制

- Mac 可回收内存估算不等于活动监视器的精确口径；共享 APFS 文件系统已用与可用量不保证相加等于卷总量。
- Linux 解析使用固定样例测试，本轮未在远程服务器重复测量；GPU/vLLM 推理验收状态不变。
- 为诊断保留英文原始输出，默认界面使用中文解释，不翻译软件名、版本号与设备 UUID。
