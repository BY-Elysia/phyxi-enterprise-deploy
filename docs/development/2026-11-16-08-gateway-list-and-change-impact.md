# 网关列表启停与配置生效说明

## 目标

在列表直接识别运行入口并操作启停；修改配置后明确显示在线应用、重启或重新签发证书的要求，不依赖用户推测。

## 变更

- 网关列表用运行状态/待处理事项替代修订号列，显示启动、停止和可执行的应用更改。不能启动时按钮禁用并给出证书、模型、运行位置或服务准备等原因；停止沿用确认对话框。
- 状态轮询最多三个请求并发；状态不变不替换控件，避免丢失焦点。请求失败清除可操作状态，显示未知与重试。
- readiness 返回结构化 impact：需要配置/修复/重新签发证书、启动时生效、在线应用、重启或已生效，并列出相对于当前运行快照变化的字段。
- 证书域名/IP不匹配判定基于实际校验：只有去掉身份检查后证书链/用途/有效期/私钥仍然有效，才归因为地址不覆盖。该诊断不用于 TLS 激活，所有激活路径仍完整校验身份。
- SAN 已覆盖的新地址不要求重签；端口/CIDR变更不会单独触发重签。原生网关及需要重新生成测试证书的场景提示先停止再启动；容器支持时在线应用。
- 保存后反馈具体要求；详情持续显示生效说明。关联模型未运行时单独提示先启动模型，不将保存网关等同于模型参数生效。

## 限制

- 原生网关重启使用明确的“先停止、再启动”两步流程；不隐藏中断，不自动切换或停止其他入口。
- 运行状态来自执行器实际快照与进程检查，不代表外部网络已经可达。
- 仅分析网关配置；模型推理启动参数的重新部署仍在部署实例页面处理。
- 服务器部署保留既有模型、网关、鉴权容器，更新控制台/执行器并保存回退材料。
