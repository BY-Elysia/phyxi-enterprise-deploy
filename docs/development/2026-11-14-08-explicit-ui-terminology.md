# 明确前端对象、动作与状态

## 目标

消除“运行环境”等混淆镜像、宿主机依赖与模型服务的名称，统一用户可见文案。

## 变更

- 导航、标题、配置选择、预设、提示和后端错误统一使用“推理引擎镜像”；明确其包含推理程序和依赖，不包含权重。
- “服务器环境”改为“服务器资源与依赖”，“工作区”改为“客户端工作区”；推理参数名称全流程一致。
- 按钮明确为启动/停止模型服务、检查服务器权重文件/镜像、安装服务器依赖、验收并记录发布版本。修订号不再暗示模型软件版本。
- 部署卡片区分待部署配置、当前模型服务、草稿应用状态；GPU 未分配不再与 CPU 模式混合，未选镜像不再推断为 CPU。
- 引擎名称和实例状态转换为用户可读名称；未运行与版本读取失败分开显示。服务器标签不再固定称“本地服务器”。
- 同步当前架构及使用文档；历史开发纪要保留原文。

## 验证

- cargo fmt --all -- --check、cargo clippy --workspace --all-targets -- -D warnings、cargo test --workspace、cargo build --workspace 通过。
- scripts/smoke-console.py、scripts/test-api-contract.py、scripts/test-presets.py 通过。
- node --check console/web/app.js、git diff --check 通过。
- 检索 console 中旧“运行环境”“运行参数”“模型镜像”等混淆称呼无残留；Docker 重建后核对实际服务资源与页面展示。

## 限制

- 不改动配置 ID、API 路由或数据库结构；用户自行命名的存量配置及历史日志不会自动重命名。
- 诊断详情保留原始日志和结构化快照，便于排错；本次不改变部署行为或新增功能。
