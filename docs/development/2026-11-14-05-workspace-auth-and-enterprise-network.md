# P1b/P3 独立工作区鉴权与企业网络

## 目标

实现不依赖控制台在线的业务鉴权，落实每工作区一个有效密钥、立即撤销新请求、已有流完成，以及模型无公开端口的四容器关系。

## 变更

新增 Rust --access 服务，独占凭据数据库与文件锁，无 Docker socket；内部管理 API 使用独立密钥，外部密钥只存 SHA256 摘要、仅展示一次，支持应用绑定、轮换、撤销、停用/启用。网关绑定变化撤销旧密钥，启用不复活旧密钥，system- 命名空间用于短期验收凭据。前端增加状态卡、明确生效操作和一次性密钥对话框。

新增企业 Compose 网络，三个固定服务、一个动态模型；仅网关发布 HTTPS 8443/18443，模型不发布端口，控制台非回环绑定强制密码模式和 Secure 会话。Nginx 无正文 auth_request 校验、可信工作区归属、无成功缓存、短超时拒绝；控制台与鉴权分别持有自己的数据库。管理入口证书通过初始化脚本验证，支持回环本地测试模式。

网关只输出结构化请求时间/路由类别/工作区/状态/耗时，Docker 日志有界；新增按工作区过滤查询。管理审计增加经过规范化的可信网关来源 IP。vLLM 启动关闭请求内容日志。旧本地令牌与原生 CPU 模式仅用于兼容测试。

## 验证

fmt、clippy -D warnings、24 项 Rust 单元测试、debug 与 Linux release Docker 构建、smoke-console.py、test-api-contract.py、test-admin-security.py、test-access-service.py、JS 语法检查通过。

真实四容器 test-enterprise-containers.py 通过：HTTPS 管理员登录、网关作用域密钥、撤销后新请求 401、已开始 SSE 完成、停止控制台后业务继续、鉴权停止拒绝/恢复、网关日志无测试提示词与密钥、模型无宿主机发布端口。模型为明确标注的 Python 协议 fixture，非 GPU 推理。初测发现虚拟机时间快约两秒，测试等待证书 NotBefore（不跳过 TLS 校验）；故障测试发现默认鉴权连接超时过长，改为 1 秒连接/2 秒读取后通过。

## 限制

正式 GPU 实机、企业 CA 客户端信任及业务模型验收仍待目标环境。证书上传目前保存草稿，在线更换入口证书与备份恢复属于后续阶段。请求日志查询限最近 200 行，不是长期审计平台；共享管理员不能识别个人。CPU 测试不在企业容器网络中运行。已明确固定的企业入口端口和网络，不能把 host 覆盖文件与企业 Compose 混用。
