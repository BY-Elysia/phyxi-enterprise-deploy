# 下载源默认设置

## 目标

降低下载对上游官方站点直连的依赖。

## 变更

模型广场和新增权重默认沿用服务器的下载站点，未配置时使用 hf-mirror。粘贴官方仓库链接后仍遵循所选下载站点，保存记录时固定实际来源和版本。模型广场提供镜像站模型卡链接。

Docker Hub 的短名称及 docker.io 地址统一经过 DaoCloud 或配置的企业代理。其他显式仓库沿用其地址。控制台构建的三个基础镜像使用同一公共代理，可通过 HUB_LIBRARY 覆盖。

## 验证

验证通过格式检查、Clippy、Rust 单元测试、控制台冒烟、API 契约、预设集成及模型广场浏览器测试。H20 实测可以读取 Qwen 模型版本元数据和 vLLM 固定摘要的镜像清单。

## 限制

仅检查元数据，未测完整大文件吞吐，未构建容器或部署。
