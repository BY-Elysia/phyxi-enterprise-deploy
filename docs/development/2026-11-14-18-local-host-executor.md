# 单机宿主机执行器与受限控制台

## 目标
落实单机管理、执行、推理接入分层，控制台不再直接操作 Docker，环境管理不再在容器内部安装宿主机依赖。

## 变更
新增 Unix socket 执行器与鉴权后的控制台 API 转发；执行器独占原有部署数据库、任务和容器归属，控制台使用独立登录目录。增加非 root、只读根文件系统且无 Docker/GPU 挂载的 compose、systemd 服务和安装迁移脚本。支持固定 NVIDIA Toolkit 安装/配置修复以及离线镜像 GPU 容器验证；限制维护任务取消，检测在线业务负载并拒绝影响外部容器。执行器模型路径限制在专用权重目录。前端明确宿主机来源、三个维护操作和执行器断线提示。补充完整架构、数据归属、部署和故障边界文档，CI增加分离架构测试。

## 验证
按用户要求在 47.120.39.81 的隔离测试目录运行，没有启动本地控制台或本地测试容器：cargo fmt、clippy（-D warnings）、cargo test（26 通过，1 个既有容器测试忽略）、cargo build、smoke-console.py、test-api-contract.py、test-executor.py 全部通过。新增测试验证匿名/非法操作拒绝、Unix socket API鉴权、配置持久化、下载任务跨控制台重启完成、执行器故障503与恢复、内部端口不提供登录或通用 Docker API。

## 限制
同机不是高可用；执行器是可信高权限程序。仅 Ubuntu 22.04/24.04 自动安装 Toolkit，不替换驱动。Docker 与驱动仍是初始化前提；初始安装不部署模型或企业接入。部署数据库由执行器保管以保证单写者，未为控制台另建配置副本。真实 A10 容器访问及在线迁移在发布包生成后验证；无新模型生成或性能结论。已有 Toolkit 的机器不能证明全新机器安装分支通过。升级前必须备份，失败按文档恢复旧版本；不做自动跨版本数据库回退。
