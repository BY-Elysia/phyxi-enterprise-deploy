# 检查反馈与提示生命周期

## 目标

修复错误提示长期驻留，以及手动检查配置后缺少可见反馈的问题。

## 变更

- 全局提示增加关闭按钮，成功6秒、错误10秒后清除；切换页面或发起下一次操作时清除旧提示。
- 手动检查时按钮禁用并显示“正在检查”，防止重复提交；使用原比较接口返回明确的完成、变更数量或失败原因。
- 检查结果显示在当前实例的独立状态区域，自动刷新参数不会覆盖该反馈；离开页面或选择其他实例后清除。
- 明确组合检查不等于权重/GPU/推理服务验收，不将无运行实例描述为运行验证成功。

## 验证

- fmt --check、clippy --all-targets -D warnings、cargo test、cargo build 通过。
- smoke-console.py、test-api-contract.py、node --check console/web/app.js、git diff --check 通过。
- 本地 Docker 更新后检查按钮加载与完成反馈、错误提示关闭及页面切换清除。

## 限制

- 不修改后端实例归属校验；无所属实例时停止、验收等操作仍会被后端拒绝。
- 失败的任务历史保留在操作记录中，全局提示清除不删除任务记录。
