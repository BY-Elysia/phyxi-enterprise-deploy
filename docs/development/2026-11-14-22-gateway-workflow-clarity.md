# 默认配置简化与网关使用流程

## 目标

默认设置不展示具体仓库地址，把企业网关从组件运维界面改为面向客户端模型访问的清晰流程。

## 变更

- 下载方式和网关镜像默认只显示“默认”，企业仓库与自定义才展开地址输入；服务端提供默认镜像值，自定义保存和恢复默认不改动正在运行的服务。
- 推理镜像列表使用默认/自定义摘要，预设新建隐藏地址输入，实际地址和 ID 放在详情/诊断。
- 网关页展示客户端 → HTTPS 网关/身份校验 → 模型的关系，拆成准备服务、配置访问地址、配置客户端并启用三个操作区。
- 组件维护、日志和整体停止折叠；常用业务操作保留上传证书、启用模型访问、接口验收，其他操作和控制台 HTTPS 入口分开折叠。
- 不新增部署步骤，不强制耦合独立配置，不增加服务容器。
