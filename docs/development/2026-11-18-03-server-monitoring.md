# 服务器监控与逐卡 GPU 趋势

## 目标

在服务器页提供主机指标和逐卡 GPU 趋势，支持从概览打开大图。

## 变更

- 新增 CPU、内存、磁盘 I/O、网络和磁盘容量视图，以及 GPU 资源和软件依赖页签。
- 显示每张 NVIDIA GPU 的计算利用率、显存使用量、占用率和 UUID。驱动无法执行扩展查询时，保留基础显存指标。
- 主机和 GPU 趋势共用 1、6、24 小时范围及刷新设置。点击图表放大，关闭时焦点返回原图。
- 监控使用执行器的只读采样和已鉴权转发。SQLite 保留近 24 小时历史。监控脚本及样式各自嵌入控制台。

## 验证

- `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace` 及锁定依赖构建通过。
- `smoke-console.py`、`test-api-contract.py` 和 `test-executor.py` 通过，覆盖执行器转发、鉴权与老驱动查询回退。
- Chrome 测试覆盖实际 macOS 采样、八卡查询夹具、放大和焦点恢复、三个时间范围、刷新暂停、缺失和过期处理、移动端以及操作任务列表。

## 限制

新历史从功能上线后开始采集。长时间范围会降采样。此次分支验证使用本机采样和 GPU 夹具，未更新 H20 服务器。
