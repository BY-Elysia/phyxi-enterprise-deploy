# P2a 管理员会话与证书上传

## 目标

在开放企业内网入口前建立管理认证和证书上传的基础；保留明确的本地兼容模式，不混用密码和令牌权限。

## 变更

增加 Argon2id 管理员密码初始化/离线重置（stdin 输入、独占状态锁、0600 哈希文件）。存在密码文件时仅接受服务端会话，旧 Bearer Token 失效；增加 Secure/HttpOnly/SameSite Cookie、8 小时过期、写操作 CSRF、登录 Origin 检查、每分钟 5 次限速、单并发有界密码哈希、退出及重启会话失效。全局 no-store、CSP 与 nosniff。前端自动识别认证模式、提供登录/退出和操作审计。

证书上传接口采用版本号保护、大小限制、权限受限的独立目录，验证证书链/域名/私钥后更新网关草稿；失败清除候选文件，原配置不变。前端提供文件选择和明确的“尚未应用”提示。新增有界管理操作审计，不记录请求体或凭据。

## 验证

fmt、clippy -D warnings、cargo test（24 通过，真实 Docker 测试默认忽略）、debug 构建、smoke-console.py、test-api-contract.py、node --check 通过。新增 test-admin-security.py 实际 HTTP 测试通过：Argon2id/0600、旧令牌拒绝、错误 Origin、登录、Secure Cookie、CSRF、退出失效、限速、无效私钥不覆盖、合法证书仅保存草稿、陈旧版本拒绝、审计无密码/私钥/CSRF。

## 限制

本提交为 P2a；正式 HTTPS 管理入口、可信来源地址审计、在线证书重载仍待 P1b/P2b。当前密码重置需本机停止服务后执行；不提供多账号和个人归属。会话在内存中，重启需重新登录。原生测试仍可使用未初始化密码的本地令牌模式；不得据此宣称企业版安全链路已全部完成。未做 GPU 验证。
