# 独立管理员登录页

## 目标

登录作为独立入口，未登录时不展示控制台导航和配置页面。

## 变更

- 新增 /login HTML 和独立 login.js，居中账户/密码表单、加载与提交状态、错误提示、回车提交和移动端布局。
- 密码模式下服务端验证首页会话，未登录直接重定向 /login，不返回控制台 HTML。
- 从控制台移除嵌入登录框；右上角保留账户与退出操作。前端完成会话校验后才展示控制台，API 401 返回登录页。
- 登录成功进入控制台；有效会话访问登录页自动进入控制台；退出清理旧开发令牌并返回登录页。
- 不修改现有管理员密码或数据库。未初始化密码的兼容测试模式保留独立开发令牌入口。

## 验证

- fmt --check、clippy --all-targets -D warnings、cargo test、cargo build 通过。
- smoke-console.py、test-api-contract.py、test-admin-security.py 通过。
- 管理员测试新增未登录首页跳转、登录页不含控制台导航、认证后首页包含控制台且无旧登录框。
- app.js、login.js 的 node --check 和 git diff --check 通过。
- 本地 Docker 重建后验证独立登录页、登录进入控制台及退出返回登录页。

## 限制

- 仍是共享 admin 账户，密码重置由服务器运维完成，不增加注册或邮件找回流程。
- 本地 HTTP 与企业 HTTPS 的会话配置保持原有边界。
