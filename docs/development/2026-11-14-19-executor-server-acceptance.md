# 执行器服务器验收、重启与双目录备份

## 目标

## 验证
所有执行测试均在服务器完成，本地未启动控制台或测试容器。服务器 fmt、clippy、cargo test（26通过、1已有测试忽略）、build、smoke-console.py、test-api-contract.py、test-executor.py 再次通过；另通过管理员安全、配置组合、镜像预设协议测试。

在线服务器已切换为非 root 只读控制台容器 + systemd 执行器；检查确认控制台无 Docker socket、GPU设备和执行器状态目录挂载。实际 A10 GPU容器验证成功（驱动580.126.09，显存24564MiB），安装任务识别依赖已齐备且未执行安装/重启。创建本测试专属的短时容器后，修复任务拒绝维护且保留容器运行，测试结束只删除该测试容器。真实 systemd 重启后，运行目录 inode 不变，已有控制台登录会话通过代理重新读取宿主机状态。页面实测登录、环境卡片、三项操作按钮和点击 GPU 验证成功。

双目录加密备份成功；在服务器临时隔离容器中按原绝对路径恢复两个归档，验证部署记录与管理员密码哈希一致，未覆盖在线目录。首次初始化脚本在当前服务器验证了“已有 Docker 不变更”分支。
