1 · 准备访问服务

准备网关和身份校验服务。此步骤不启动模型，也不创建业务访问地址。

2 · 配置模型访问地址

选择已部署的模型，填写域名、证书与允许访问的网络。

先为客户端创建工作区和 API Key，再回到所选入口点击“启用模型访问”，最后执行“接口验收”。
