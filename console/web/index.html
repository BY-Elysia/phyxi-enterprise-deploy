其他推理方案
llama.cpp
适合 GGUF 量化模型。本控制台已有受限 CPU 测试后端，暂不作为 GPU 镜像预设。
Ollama
使用独立模型管理与导入流程，暂未接入本控制台的权重和运行生命周期。
TensorRT-LLM / NIM
NVIDIA 优化方案，需要单独适配模型构建、镜像和运行配置。
TGI
官方已进入维护模式，不作为新增默认后端。

    生成证书申请
    在服务器生成私钥和 CSR。将 CSR 交给企业 CA 签发，私钥始终留在服务器。
    

    

    上传 CA 签发结果
    支持 PEM 格式，每个文件最大 64 KiB。自动校验域名 / IP、有效期、服务器用途、信任链及私钥匹配。证书保存后自动关联此网关，无需填写路径。
    

    

    保存后返回网关详情，按页面提示让新证书生效。当前运行入口不会因上传而中断。
